# AppRentCar – Aplicación de registro y renta de vehículos
   🔗 **Demo en vivo:** https://apprentcar.pages.dev/


## Funcionalidades

- Registro de vehículos.
- Renta de vehículos.

## Tecnologías

| Área | Tecnología |
| --- | --- |
| Lenguaje | TypeScript |
| Herramienta de desarrollo | Vite |
| Diseño de interfaz | Figma |
| Despliegue | Cloudflare (`wrangler`) |

## Cómo ejecutarlo en tu computadora

Necesitas tener instalado [Node.js](https://nodejs.org/) (versión 18 o superior).

```bash
# 1. Clonar el repositorio
git clone https://github.com/abrilandino/apprentcar.git
cd apprentcar

# 2. Instalar dependencias
npm i

# 3. Iniciar el servidor de desarrollo
npm run dev
```

Después abre en el navegador la dirección que aparece en la terminal (normalmente `http://localhost:5173`).
